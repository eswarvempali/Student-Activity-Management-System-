# Student Details Management System

This project is a Student Details Management System built with React and TypeScript. It allows users to manage student information, including viewing, adding, and editing student details.

## Features

- **Dashboard**: A main landing page that provides an overview of the application.
- **Student List**: Displays a list of students with options to view details and edit information.
- **Student Detail**: Shows detailed information about a selected student.
- **Student Form**: A form for adding new students or editing existing student details.
- **Search Functionality**: Allows users to search for students by name or other criteria.
- **Pagination**: Handles pagination for the student list to improve usability.
- **Responsive Design**: The application is designed to be responsive and user-friendly.

## Technologies Used

- React
- TypeScript
- React Router
- CSS

## Getting Started

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd student-details-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

5. Open your browser and go to `http://localhost:3000` to view the application.
